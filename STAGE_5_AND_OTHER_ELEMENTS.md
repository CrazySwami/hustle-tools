# Style Kit Generation - Complete Element List

## 📋 STAGE 5: Images & Layout Elements

### Image Styles (`image_styles`)
- `image_border_radius` (object with `unit`, `top`, `right`, `bottom`, `left`, `isLinked`)
- `image_object_fit` (string: "cover", "contain", "fill", "none", "scale-down")
- `image_box_shadow` (string: CSS shadow value)
- `image_placeholder_color` (string: hex color)
- `image_caption_typography` (object with typography properties):
  - `typography_typography`: "custom"
  - `typography_font_family` (string)
  - `typography_font_size` (object with `unit`, `size`, `sizes`)
  - `typography_font_weight` (string)
  - `typography_line_height` (object with `unit`, `size`)
  - `typography_text_transform` (string)
  - `typography_letter_spacing` (object with `unit`, `size`)
- `image_caption_color` (string: hex color)

### Layout Settings
- `container_width` (object with `unit`, `size`, `sizes`)
- `space_between_widgets` (object with `unit`, `size`, `sizes` OR `column`, `row`, `isLinked`, `unit`)
- `viewport_md` (number: tablet breakpoint, default 768)
- `viewport_lg` (number: desktop breakpoint, default 1025)

## 📋 STAGES 1-4: Generated Elements

### STAGE 1: Colors
- `system_colors` (array of 4 objects with `_id`, `title`, `color`)
- `custom_colors` (array of objects with `_id`, `title`, `color`)

### STAGE 2: Typography System
- `primary_font` (string)
- `secondary_font` (string)
- `system_typography` (array of 4 objects: primary, secondary, text, accent)
  - Each with complete typography properties (font_family, font_size, font_weight, line_height, etc.)

### STAGE 3: Headings
- `h1_typography` through `h6_typography` (objects with typography properties)
- `body_typography` (object with typography properties)
- `body_color` (string: hex color)
- `link_normal_color` (string: hex color)

### STAGE 4: Components
- `button_typography` (object with typography properties)
- `button_text_color` (string: hex color)
- `button_background_color` (string: hex color)
- `button_border_width` (object with `unit`, `top`, `right`, `bottom`, `left`, `isLinked`)
- `button_border_radius` (object with `unit`, `top`, `right`, `bottom`, `left`, `isLinked`)
- `form_field_typography` (object with typography properties)
- `form_field_text_color` (string: hex color)
- `form_field_background_color` (string: hex color)
- `form_field_border_color` (string: hex color)
- `form_field_border_radius` (object with `unit`, `top`, `right`, `bottom`, `left`, `isLinked`)
- `form_field_border_width` (object with `unit`, `top`, `right`, `bottom`, `left`, `isLinked`)

---

## ⚠️ ELEMENTS NOT GENERATED BY STAGES 1-5

These elements exist in the default template but are **NOT generated by any stage**. They come from the base template and are not AI-generated:

### Button Hover & Focus States
- `button_hover_background_color` (string: hex color)
- `button_hover_text_color` (string: hex color)
- `button_focus_outline_color` (string: hex color)
- `button_focus_outline_width` (object with `unit`, `size`, `sizes`)
- `button_padding` (object with `unit`, `top`, `right`, `bottom`, `left`, `isLinked`)

### Form Field Focus States
- `form_field_padding` (object with `unit`, `top`, `right`, `bottom`, `left`, `isLinked`)
- `form_field_focus_border_color` (string: hex color)
- `form_field_focus_shadow_color` (string: rgba color)

### Other Template Fields
- `title` (string: set from stylePreferences if provided, otherwise from template)
- `description` (string: from template)
- `type` (string: always "kit")
- `version` (string: always "0.4")
- `custom_typography` (array: empty by default)
- `content` (array: empty by default)
