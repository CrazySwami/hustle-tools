## 1. Project Generation API

**Location:** `/src/app/api/generate-project/route.ts`

### 1.1 Elementor Widget Generation
- **Lines:** ~279-360
- **Purpose:** Generate WordPress Elementor widgets as a SINGLE PHP file with inline CSS/JS
- **Key Features:**
  - Generates ONLY ONE PHP file with CSS/JS inline in render() method
  - NO separate CSS or JS files
  - Enforces user instructions as highest priority
  - Scoped CSS with `{{WRAPPER}}` prefix inside <style> tag
  - JavaScript wrapped in IIFE inside <script> tag (if needed)
  - Comprehensive Elementor controls for ALL editable elements
  - Security best practices (nonce verification, sanitization, escaping)
  - Professional PHP structure with proper namespacing

### 1.2 HubSpot Email Module
- **Lines:** ~102-160
- **Purpose:** Generate HubSpot email modules (strict table-based layouts)
- **Key Features:**
  - Table-based layout with inline styles
  - Email client compatibility (Gmail, Outlook, Apple Mail)
  - NO flexbox/grid (email compatibility)
  - HubL tokenization for dynamic content
  - Outlook-safe markup

### 1.3 HubSpot Page Module
- **Lines:** ~161-223
- **Purpose:** Generate HubSpot page modules (modern web standards)
- **Key Features:**
  - Modern HTML5 with semantic elements
  - Flexbox and Grid allowed
  - Modern CSS (variables, media queries, animations)
  - JavaScript support (vanilla JS or jQuery)
  - Responsive design patterns

### 1.4 HTML Project
- **Lines:** ~224-237
- **Purpose:** Generate standalone HTML/CSS/JS sections
- **Key Features:**
  - Section-level markup only (no DOCTYPE, html, head, body)
  - Modern layout (flexbox/grid)
  - Responsive design (mobile-first)
  - Vanilla JS only (no frameworks)
  - Accessibility best practices

## Prompt Design Patterns

### Common Elements Across All Prompts:

1. **Current Date & Time** - All prompts include temporal context
2. **User Instructions Priority** - User's instructions are HIGHEST PRIORITY
3. **Tool-First Approach** - Prompts encourage specific tool usage
4. **Context Awareness** - Include relevant file contents and project state
5. **Professional Standards** - Security, accessibility, best practices
6. **Streaming Support** - Designed for real-time code/text generation

### Model-Specific Adaptations:

- **Perplexity Models:** Search-first prompts with mandatory web search
- **Reasoning Models:** Extended thinking budgets (12000 tokens for Claude)
- **Vision Models:** Image analysis for mockup-to-code generation

## How to Edit System Prompts

### For API Prompts:
1. Locate the prompt in the file listed above
2. Modify the template string (usually backtick-delimited)
3. Test with various inputs to ensure behavior is correct
4. Update `generate-*-system-prompt.ts` if client-side matching is needed

### For Client-Side Prompt Generators:
1. Edit the shared function in `/src/lib/generate-*-system-prompt.ts`
2. Changes automatically apply to both API and Token Viewer
3. Ensures accurate token counting

### Testing Checklist:
- [ ] Prompt includes Current Date & Time
- [ ] User instructions prioritized
- [ ] Tool usage instructions clear
- [ ] Context includes necessary files
- [ ] Tested with target model
- [ ] Token count estimated (use Token & Prompt Viewer)
